Vamos a trabajar sobre un proyecto de entregas a traves de una pagina web.
Vamos a dividir el proyecto en tareas, somos 4 personas y luego vamos a unificar las tareas para que funcione como un proyecto.
Vamos a hacer una pagina web que permita gestionar entregas de productos(Como Uber Eats).
Para la pagina web(back end) utilizar Node.js y express.
Vamos a utilizar HTML y CSS(front end).
El proyecto debe tener acceso a un administrador y un repartidor y el usuario consumidor.
Dividiremos el proyecto en dos semanas. La primer semana generaremos la entrega de tareas para el funcionamiento de la pagina Web y en  la segunda semana implementaremos descuentos en la plataforma y el uso de inteligencia artificial para brindar opciones de compra a los usuarios.
